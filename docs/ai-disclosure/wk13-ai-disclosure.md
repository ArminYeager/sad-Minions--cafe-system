# แบบฟอร์มการเปิดเผยการใช้งาน AI (AI Disclosure Form) - สัปดาห์ที่ 13

**รหัสนิสิต:** 67160042 (และตัวแทนกลุ่ม 14 Minions Cafe)  
**ชื่องาน:** การรวมระบบและการทดสอบ + Coding Sprint 3 (สัปดาห์ที่ 13)

## 1. การใช้งาน AI ในขั้นตอนการรวมระบบ (Integration) และ Test Cases
- **เครื่องมือที่ใช้:** Gemini / Antigravity AI
- **คำสั่ง (Prompt) ที่ใช้:** "ช่วยออกแบบ Test Case สำหรับการทดสอบ End-to-End ของ flow การสั่งซื้อเครื่องดื่ม (order -> payment -> report) และตรวจสอบ API Contract ระหว่าง frontend กับ backend"
- **การนำมาปรับปรุง:** นำโครงสร้าง Test Case และเกณฑ์การตรวจสอบ camelCase กับ snake_case มาใช้ปรับปรุงโค้ดระหว่าง frontend และ backend ให้ทำงานเชื่อมโยงกันอย่างถูกต้อง

## 2. การใช้งาน AI ในขั้นตอนการทำ Bug Fixing และ Refactoring
- **เครื่องมือที่ใช้:** Gemini / Antigravity AI
- **คำสั่ง (Prompt) ที่ใช้:** "แนะนำแนวทางการจัดการข้อผิดพลาดเมื่อเกิดกรณีสต็อกสินค้าไม่เพียงพอ และการคำนวณยอดขายรวมใน endpoint getSalesReport"
- **การนำมาปรับปรุง:** นำคำแนะนำเรื่องการตรวจสอบ `stock_quantity` และการจัดกลุ่มข้อมูล `GROUP BY` ใน SQL มาใช้ใน `orderController` และ `reportController`

## 3. สิ่งที่ได้เรียนรู้จากการใช้งาน AI ในสัปดาห์นี้
- เข้าใจความสำคัญของ API Contract และการทดสอบแบบ End-to-End เพื่อให้มั่นใจว่าแต่ละโมดูลทำงานร่วมกันได้อย่างสมบูรณ์
- เรียนรู้การนำ feedback จากการรัน prototype มาปรับปรุง requirement (เช่น FR-11 การปิดปุ่มเมื่อสต็อกหมด) เพื่อให้สอดคล้องกับพฤติกรรมจริงของผู้ใช้

## 4. การตรวจสอบความถูกต้อง (Verification)
- ได้ตรวจสอบและทดสอบโค้ดจริงทุกขั้นตอนด้วยตนเอง โดยทดสอบผ่านหน้าจอ POS และเรียก API ทุกจุดเพื่อให้มั่นใจว่าผลลัพธ์ถูกต้องและไม่มีข้อผิดพลาดหลงเหลือ
