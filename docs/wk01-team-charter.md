## 1. ข้อมูลภาพรวมโครงงาน (Project Overview)
โครงการพัฒนาระบบร้าน Minions Cafe เป็นการพัฒนาระบบบริหารจัดการร้านกาแฟ (Point of Sale & Coffee Shop Management System) เพื่อช่วยแก้ไขปัญหาความผิดพลาดในการรับออเดอร์ ความล่าช้าในการคิดเงิน การจัดการสต็อกวัตถุดิบที่ไม่แม่นยำ และการขาดระบบรายงานยอดขายแบบเรียลไทม์ โดยระบบรองรับโครงสร้างแบบหลายสาขา (Multi-branch)

---

## 2. องค์ประกอบ 6 ด้านของระบบสารสนเทศ (Information System Components)

### 2.1 People (บุคลากรและผู้มีส่วนได้ส่วนเสีย)
- **เจ้าของร้าน (Owner):** ตรวจสอบยอดขายรวม สรุปรายงานรายวัน/รายเดือน วางแผนการจัดซื้อวัตถุดิบ
- **ผู้จัดการร้าน (Manager):** ดูแลการดำเนินงานประจำสาขา จัดการข้อมูลเมนูและตรวจสอบสต็อก
- **พนักงานรับออเดอร์/แคชเชียร์ (Cashier/Barista):** รับออเดอร์หน้าร้าน บันทึกรายการ คิดเงิน และออกใบเสร็จ
- **พนักงานบัญชี (Accountant):** ตรวจสอบยอดรายรับรายจ่าย ปิดงบประจำรอบ
- **ลูกค้า (Customer):** เลือกสั่งเครื่องดื่ม ชำระเงิน และรับใบเสร็จ
- **ผู้จัดส่งวัตถุดิบ (Supplier):** ส่งมอบวัตถุดิบตามรอบการสั่งซื้อ

### 2.2 Process (กระบวนการทำงาน)
1. ลูกค้าแจ้งความต้องการสั่งสินค้า/เครื่องดื่ม
2. พนักงานเลือกรายการและระบุจำนวนผ่านหน้าจอ POS
3. ระบบคำนวณราคารวมอัตโนมัติแบบเรียลไทม์
4. พนักงานตรวจสอบรายการและรับชำระเงิน (เงินสด หรือ QR Code)
5. ระบบบันทึกคำสั่งซื้อ สร้างหมายเลขออเดอร์ และออกใบเสร็จรับเงิน
6. ระบบตัดสต็อกสินค้าและวัตถุดิบอัตโนมัติทันที
7. หากสต็อกสินค้าต่ำกว่าเกณฑ์ ระบบจะแสดงสถานะแจ้งเตือน
8. ข้อมูลยอดขายถูกส่งเข้าสู่ระบบรายงานยอดขายแบบทันที (Real-time Report)
9. เจ้าของร้านสามารถตรวจสอบสรุปยอดขายแยกรายสาขาและภาพรวมได้ทุกที่ทุกเวลา

### 2.3 Data (ข้อมูลในระบบ)
- ข้อมูลสาขา (Branch Data: รหัสสาขา, ชื่อสาขา, ที่ตั้ง)
- ข้อมูลพนักงานและผู้ใช้งาน (Employee Data: รหัส, ชื่อ, ตำแหน่ง, สาขาที่สังกัด)
- ข้อมูลหมวดหมู่และเมนูสินค้า (Menu & Category Data: รหัสเมนู, หมวดหมู่, ชื่อเมนู, ราคา, จำนวนสต็อก)
- ข้อมูลคำสั่งซื้อและรายการสินค้า (Order & Order Item Data: รหัสออเดอร์, วันเวลา, วิธีชำระเงิน, รายการ, จำนวน, ราคาต่อหน่วย)
- ข้อมูลการเคลื่อนไหวสต็อก (Stock Movement Data: รหัสการเคลื่อนไหว, จำนวนที่เปลี่ยนแปลง, วันเวลา)
- ข้อมูลสรุปยอดขาย (Sales Summary Data)

### 2.4 Hardware (ฮาร์ดแวร์)
- เครื่องคอมพิวเตอร์ / แท็บเล็ต สำหรับจุดรับออเดอร์ (POS Terminal)
- เครื่องพิมพ์ใบเสร็จรับเงิน (Thermal Receipt Printer)
- เครื่องสแกนบาร์โค้ด / หน้าจอแสดงผลสำหรับลูกค้า (Customer Display)
- สมาร์ตโฟน / แท็บเล็ต สำหรับเจ้าของร้านตรวจสอบรายงาน
- เราเตอร์ (Wi-Fi Router) ประจำร้าน

### 2.5 Software (ซอฟต์แวร์)
- ระบบเว็บแอปพลิเคชัน Minions Cafe POS (HTML5, Vanilla CSS, JavaScript)
- ระบบ Backend Web Server (Node.js & Express Architecture)
- ระบบฐานข้อมูลเชิงสัมพันธ์ (Relational Database: MySQL 8.0)
- เครื่องมือทดสอบและพัฒนา: Git, GitHub, VS Code, REST Client

### 2.6 Network (เครือข่าย)
- เครือข่ายไร้สายภายในร้าน (Local Wi-Fi Network)
- อินเทอร์เน็ตความเร็วสูง (Broadband Internet)
- การเชื่อมต่อสื่อสารระหว่าง Client และ Application Server ผ่าน HTTP/REST API
- ระบบฐานข้อมูลส่วนกลางสำหรับรองรับการซิงก์ข้อมูลระหว่างสาขา

## 3. แนวทางการพัฒนาซอฟต์แวร์: เลือกใช้ Agile (Scrum/Kanban)

### เหตุผลในการเลือกใช้:
1. **ความต้องการของธุรกิจร้านกาแฟเปลี่ยนแปลงได้เสมอ (Embracing Change):**
   - ร้านอาจมีการปรับเปลี่ยนราคา เมนูโปรโมชั่น หรือรูปแบบการคิดเงินตามพฤติกรรมลูกค้า การพัฒนาแบบ Agile รองรับการปรับเปลี่ยน Requirement ได้โดยไม่กระทบโครงสร้างหลักทั้งหมด
2. **ส่งมอบระบบที่ใช้งานได้จริงอย่างรวดเร็ว (Early and Continuous Delivery):**
   - เริ่มต้นพัฒนาจากฟังก์ชันหลักที่สำคัญที่สุดก่อน คือ **ระบบขายหน้าร้าน (POS)** และการตัดสต็อก จากนั้นจึงขยายไปยังระบบจัดการเมนู ระบบรายงานยอดขาย และระบบหลายสาขา
3. **พัฒนาและทดสอบเป็นรอบสั้น ๆ (Iterative & Incremental):**
   - ได้รับ Feedback จากผู้ใช้งานและผู้สอนในทุกสัปดาห์ (Sprint Review) ทำให้สามารถปรับปรุง Usability และความถูกต้องของระบบได้อย่างต่อเนื่องตรงตามความต้องการผู้ใช้จริง
